# Auditable 2026 · Kit de marca y plantillas

Carpeta maestra para que cualquier persona (o cualquier sesión de Claude) produzca informes, guías, cotizaciones y documentos Word/PDF con la marca **Auditable**: logo, márgenes, colores, tipografía y componentes ya aprobados.

## Empieza aquí
1. **`auditable_2026.md`**: la norma completa (fuente única de verdad). Se lee siempre primero.
2. **`logos_auditable.md`**: todos los logos en texto (SVG inline + PNG en base64), para cuando el canal no sincroniza imágenes.
3. **`04_plantillas/`**: diseños aprobados (se abren en el navegador).
4. **`05_word/`**: generador de Word con la marca.

## Prompt para Claude
> Lee `auditable_2026.md` y `logos_auditable.md` completos y síguelos como norma. Aplica el branding de Auditable al archivo que te adjunto, sin cambiar ni eliminar su contenido. Entrégalo en [Word / PDF / HTML], tamaño carta.

`#F20530` Rojo · `#020A1B` Deep Blue · `#0C2649` Blue · `#C5E3EF` Sky Blue · `#E6EAF1` Gray. Tipografías: IBM Plex Serif + IBM Plex Sans.
